# LykkeLiga IT Register – Warroom style

Mørk dashboard-version inspireret af LykkeLiga Warroom.

Funktioner:
- årlig pris
- noter
- status: Aktiv / Undersøg / Opsig
- nye systemer
- søgning og filtre
- dashboard med kendt årlig udgift og manglende priser
- kategorifordeling
- JSON-backup

Denne standalone-version gemmer fortsat data i browserens localStorage.
